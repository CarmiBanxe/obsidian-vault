To create a new knowledge note:

1. **Patterns** (repeatable technical solutions):
   - File: `knowledge/patterns/kebab-case-title.md`
   - Tags: `#pattern #banxe`

2. **Decisions** (one-time architecture choices):
   - File: `knowledge/decisions/YYYY-MM-DD-decision-title.md`
   - Tags: `#decision #banxe`

3. **Session logs**:
   - File: `sessions/YYYY-MM-DD.md`
   - Contains: what was done, decisions made, links to relevant notes

4. **Inbox** (quick capture):
   - File: `inbox/quick-note.md`
   - Process later: move to knowledge/ when refined
