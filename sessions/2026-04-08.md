## Ключевые решения

1. **crontab → systemd**: Persistent=true для FCA audit trail (IL-043)
2. **FastAPI sandwich pattern**: Pydantic v2 models ↔ domain dataclasses ↔ ports
3. **Dependency injection override в тестах**: `app.dependency_overrides[fn] = lambda: fresh_instance` — изолирует каждый тест
4. **Decimal strings**: все финансовые суммы как string в API (I-05), никаких float
5. **Enum mismatch**: RiskLevel.LOW = "low" (lowercase), KYCType = INDIVIDUAL/BUSINESS/SOLE_TRADER (не KYC/KYB)
